# TOTP Views

TOTP enrollment: QR scanning and the incoming-URL destination picker.

## Screen Map

- `TOTPQRScannerSheet.swift` (whole file `#if os(iOS)`; VisionKit's `DataScannerViewController` does not exist on macOS, where the scan affordance is hidden) is the TOTP enrollment camera sheet: a `DataScannerViewController` representable restricted to QR symbology. Scanning starts from a deferred main-actor task with one retry (`startScanning()` fails before the scanner is on screen), a still-failing start shows the unavailable state, and `dismantleUIViewController` stops the camera. The first payload that parses as a supported `otpauth://` URI completes the sheet; any other QR shows a transient hint, debounced per payload SHA-256 digest (rejected payloads can carry secrets and are never retained). Unsupported hardware and denied permission render `ContentUnavailableView`s (denied offers "Open Settings"; availability is re-checked when the scene becomes active). `NSCameraUsageDescription` lives in `../../Info.plist`, localized via `../../Resources/InfoPlist.xcstrings`. Cancel is `entry-edit.totp.scan-cancel`. XCUITest cannot drive the camera, so this sheet has no UI-test coverage; keep URI handling in the unit-tested `OTPAuthURI`.
- `TOTPEnrollmentDestinationView.swift` is the destination picker presented at the app root (`../../App/KeeForgeApp.swift`) for an incoming `otpauth://` URL. Header summary (`totp-enroll.summary`), a "New Entry" path (`totp-enroll.new-entry`) that pushes a flattened group picker (`totp-enroll.group.<uuid>`, visible root first, recycle bin excluded) and opens the create-mode editor prefilled from the URI, and a searchable existing-entry list (`totp-enroll.entry-list`, rows `totp-enroll.entry.<uuid>`, plain `TextField` search `totp-enroll.search-field` — local filtering in `../../ViewModels/TOTPEnrollmentViewModel.swift`, never the session's global `searchText`). Attaching over an entry that already has a code confirms first (`totp-enroll.replace-confirm`). One path-driven `NavigationStack` over a step enum; both paths open the normal `EntryEditView` with `applyOTPAuthURI` pre-applied — pushed on iOS, a sheet on macOS. Saving (or deleting) finishes the flow; cancelling the editor pops back to the destination list so a wrong pick does not destroy the incoming code (why `EntryEditView.Completion` distinguishes `.saved` from `.cancelled`). A read-only session renders an explanatory `ContentUnavailableView`. Cancel is `totp-enroll.cancel`. No UI-test coverage on purpose (XCUITest cannot deliver custom-scheme URLs reliably); the decision logic is unit-tested in `../../../KeeForgeTests/TOTPEnrollmentViewModelTests.swift`.

Shared UI shells and the folder-wide UI rules live in `../README.md`.
