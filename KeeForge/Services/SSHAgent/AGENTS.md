# SSH Agent Services

The macOS-only SSH agent (#163): an opt-in Unix-socket agent that signs with private keys stored as attachments in the unlocked database. Every file here is `#if os(macOS)` and excluded from the iOS target in `../../../project.yml`; none is on the AutoFill allow-lists. Setup and supported keys for users: `../../../KeeForgeMac/README.md#ssh-agent`. Security boundary: `../../../KeeForgeMac/SECURITY.md#ssh-agent`.

## Main Files

- `SSHAgentKey.swift` parses one unencrypted OpenSSH private key (`openssh-key-v1`, cipher and KDF `none`) and signs with it: Ed25519 and ECDSA P-256/P-384/P-521 through CryptoKit, RSA through `SecKeyCreateSignature` with `rsa-sha2-256` or `rsa-sha2-512` only. OpenSSH files carry no RSA CRT exponents, so the file derives them (`BigUnsigned`) to build the PKCS #1 key `SecKeyCreateWithData` needs. Parsing rejects mismatched check integers, bad padding, a container public key that differs from the one the private key derives, and RSA keys outside OpenSSH's 1024 to 16384 bit range or with a component longer than the modulus; the size limit is also what keeps `BigUnsigned`'s quadratic arithmetic bounded for a crafted attachment. Errors distinguish `passphraseProtected` and `unsupportedFormat` for Settings. `SSHWireReader` and `SSHWireWriter` are the RFC 4251 encoding shared by the folder and its tests.
- `SSHAgentRequestHandler.swift` answers agent messages (draft-miller-ssh-agent): `REQUEST_IDENTITIES` and `SIGN_REQUEST`; everything else, including add/remove/lock requests and extensions such as `session-bind@openssh.com`, gets `SSH_AGENT_FAILURE`. It reads `keySources` on every request and again after signing, and withholds the signature unless the same entry is still offered under the same `SSHAgentLease` (session identity plus `lockCycleID`) with the same key file, so a lock, deselection, or replaced key attachment mid-signature releases nothing. `SSHAgentKeySource.privateKeyFile` picks the attachment a `KeeAgent.settings` attachment names when its location is an attachment, otherwise the first attachment `SSHAgentKey.looksLikePrivateKey` accepts. A key on two entries is listed once; an empty key comment falls back to the entry title.
- `SSHAgentSocketServer.swift` owns the POSIX socket: bind with a 0600 mode, replace a stale socket but refuse any other file at the path, accept only peers whose `getpeereid` user matches, one thread per connection and at most `defaultMaximumConnections` (64) of them, with a further connection closed unanswered, OpenSSH's 256 KiB message limit, and `stop()` shutting every open connection down before removing the socket.
- `MacSSHAgentController.swift` is the `@MainActor @Observable` owner the app creates next to `MacQuickAccessController`: `isEnabled` and the per-database entry choice persist through `SettingsService` (app-local defaults, off and empty by default), `keySources()` reads the active `DatabaseViewModel` (empty unless the agent is on, the session is unlocked, and `isLockPending` is false: no deferred lock, window-close prompt, or Retry Save and Lock write in progress), and `candidates(in:)` builds the Settings list off the main actor; the tab clears its rows when a refresh starts and drops the result of a refresh that was superseded. Socket threads reach the session through `DispatchQueue.main.sync`, so nothing on the main actor may wait for a socket thread. `../../Views/Settings/MacSSHAgentSettingsTab.swift` is its view.

## Change Carefully

- Keep the agent stateless about keys: no caching of parsed keys, no key export, no writing key files. A lock must withdraw keys by the next read, and that only holds while every request reads the session afresh.
- Keep the default socket path stable; users paste it into `~/.ssh/config`.
- Tests: `../../../KeeForgeTests/SSHAgentKeyTests.swift`, `SSHAgentRequestHandlerTests.swift`, and `MacSSHAgentControllerTests.swift`, all macOS-only, over the throwaway keys in `../../../KeeForgeTests/Support/SSHAgentTestKeys.swift`.
