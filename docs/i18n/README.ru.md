## Почему KeeForge?

KeeForge — нативный клиент KeePass для iPhone, iPad и Mac для тех, кто хочет, чтобы хранилище паролей оставалось в их собственных руках. Открывайте базы данных `.kdbx` из локальных файлов или через WebDAV на любой платформе, а на iPhone и iPad — также из iCloud Drive, Dropbox, OneDrive и других провайдеров приложения «Файлы»; разблокируйте их мастер-паролем, файлом ключа или с помощью биометрии; затем просматривайте, ищите, редактируйте, сохраняйте и используйте автозаполнение, не передавая хранилище облачному сервису паролей.

## Основные возможности

| Область | Что делает KeeForge |
| --- | --- |
| **Совместимость с KeePass** | Читает и записывает базы данных KDBX 4.x с шифрованием AES-256, ChaCha20 или Twofish и формированием ключа AES-KDF, Argon2d или Argon2id. Также открывает базы данных KDBX 3.1 в режиме только для чтения. |
| **Локальное редактирование** | Создание, изменение, перемещение и удаление записей и групп; сохранение с проверкой конфликтов, резервными копиями с отметкой времени и сохранением истории записей и неизвестного XML. |
| **Новые базы данных** | Создание новых баз данных KDBX 4.x локально или через WebDAV на любой платформе, а на iPhone и iPad — прямо в Dropbox или OneDrive. |
| **Составные ключи** | Разблокировка паролем, файлом ключа или обоими, включая двоичные, шестнадцатеричные, XML v1/v2 (`.key`/`.keyx`) и произвольные файлы ключей. |
| **Автозаполнение** | Нативное автозаполнение паролей в приложениях и браузерах с биометрической разблокировкой, а также регистрация ключей входа на любой платформе; на iPhone и iPad дополнительно доступны подсказки QuickType и создание записей с паролями прямо из расширения. |
| **Ключи входа** | Обнаружение и аутентификация с ключами входа FIDO2/WebAuthn, хранящимися в пользовательских полях, совместимых с KeePassXC. |
| **TOTP** | Отображение одноразовых паролей в реальном времени, копирование и обратный отсчёт на любой платформе, а также автозаполнение кодов проверки в iOS 18+ и на Mac. |
| **Облачная синхронизация** | Просмотр WebDAV и синхронизация с чтением и записью на любой платформе. Интеграция с Dropbox и OneDrive пока доступна на iPhone и iPad; на Mac синхронизируемые папки можно открывать как локальные файлы. |
| **Вложения** | Просмотр вложений записей KeePass, предпросмотр поддерживаемых файлов через Quick Look и отправка их из кратковременных защищённых временных файлов. Редактирование вложений пока не поддерживается. |
| **Нативно на каждом экране** | Удобная навигация на iPhone, рабочее пространство с разделённым экраном на iPad и нативное приложение для Mac, оптимизированное для компьютера, с меню, командами и Touch ID. |
| **Безопасность** | Шифрование секретов в памяти с AES-GCM, увеличение задержки после неудачных попыток разблокировки, ограничения против декомпрессионных бомб и сравнение HMAC за постоянное время. |

## Конфиденциальность

В KeeForge нет аналитики, фоновой телеметрии и SDK для отчётов о сбоях. Данные хранилища остаются на устройстве и в выбранных вами местах хранения. Доступ к сети ограничен подключёнными облачными провайдерами, загрузкой значков сайтов через DuckDuckGo (только с вашего согласия), необязательными покупками чаевых в App Store, проверкой обновлений в версии для Mac, загружаемой напрямую, и формой отзыва в приложении, когда вы сами отправляете сообщение.

На iPhone и iPad скопированные секреты помечаются как локальные, поэтому не передаются через универсальный буфер обмена. macOS такого исключения не предлагает, поэтому скопированные секреты могут попасть в универсальный буфер обмена в зависимости от настроек системы; KeeForge помечает их как скрытые и очищает свою запись в буфере обмена через некоторое время или при блокировке базы данных. Кроме того, на iPhone и iPad KeeForge защищает миниатюры в переключателе приложений. Блокировка записи экрана на Mac работает по возможности и может не помешать каждому снимку или записи экрана.

Ознакомьтесь с [политикой конфиденциальности](https://keeforge.com/privacy) (на английском языке).

## Сохранность данных

KeeForge очень серьёзно относится к сохранности данных: менеджер паролей никогда не должен повреждать хранилище или незаметно терять какую-либо его часть. Прежде чем любое изменение попадёт в выпуск, автоматические тесты проверяют следующее:

- **При сохранении ничего не теряется.** Каждый вид изменения сохраняется и читается обратно по частям — пароли, заметки, вложения, история записей и даже данные из других приложений KeePass, которые KeeForge не распознаёт, должны вернуться в точности такими, какими были.
- **Файл защищён ещё до того, как его коснутся.** KeeForge проверяет, не изменили ли файл где-то ещё, пока он был открыт, и отказывается сохранять при обнаружении конфликта, перед каждым сохранением создаёт резервную копию с отметкой времени и сразу отклоняет повреждённые базы данных, а не загружает частичные данные.
- **Независимая программа это подтверждает.** Каждый выпуск должен пройти проверку, в которой KeePassXC — широко используемое приложение KeePass, не имеющее общего кода с KeeForge, — открывает базы данных, записанные KeeForge, расшифровывает пароли и подтверждает побитовое совпадение вложений. Базы данных, созданные другими программами KeePass, также должны открываться в KeeForge и оставаться читаемыми в других приложениях после сохранения в KeeForge.

При работе через FTP последнюю проверку конфликтов и замену файла нельзя выполнить одной операцией. Одновременное сохранение из другого приложения или устройства всё же может быть перезаписано, поэтому не изменяйте базу данных на FTP в двух местах одновременно.

Для интересующихся техническими подробностями: набор тестов описан в [`KeeForgeTests/AGENTS.md`](../../KeeForgeTests/AGENTS.md), а проверка перед выпуском — в [`ci_scripts/README.md`](../../ci_scripts/README.md).

## Карта проекта

```text
KeeForge/
├── App/              # Точка входа приложения, адаптивная корневая оболочка, жизненный цикл сцен
├── Extensions/       # Общие вспомогательные средства для совместимости платформ
├── Models/           # Парсер и запись KDBX, криптография, черновик изменений, TOTP, ключи входа
├── Resources/        # Каталоги строк и каталоги ресурсов
├── Services/         # Хранение, облачная синхронизация, связка ключей, закладки, вложения, вспомогательные средства автозаполнения
├── ViewModels/       # Список баз данных, разблокировка, сохранение, поиск, сортировка, состояние TOTP
├── Views/            # Экраны SwiftUI, редактор, настройки, чаевые, повторно используемые элементы управления
AutoFillExtension/    # Поставщик учётных данных для автозаполнения, аутентификация с ключами входа, создание учётных данных
KeeForgeMac/          # Конфигурация и entitlements нативного приложения для macOS
KeeForgeMacUITests/   # Тесты XCUITest для приложения macOS
KeeForgeTests/        # Модульные тесты
KeeForgeUITests/      # Тесты XCUITest
TestFixtures/         # Примеры баз данных .kdbx и файлов ключей
Vendor/               # Встроенный пакет Swift KeeForgeTwofish
ci_scripts/           # Начальная настройка Xcode Cloud и скрипты проверок перед выпуском
scripts/              # Локальные инструменты разработки
```
